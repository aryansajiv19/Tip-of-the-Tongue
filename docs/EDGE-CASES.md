# Edge cases

Each row says what is true today and how it is covered: a named test, the eval, a documented limitation, or not handled.

| Case                                                         | Risk                                | What happens today                                                                                                                                                                                          | Status                                                                                                                                                                                                                                                                                             |
| ------------------------------------------------------------ | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| User finds the word themselves just before the guess appears | Redundant or patronising offer      | The gate drops any candidate already said since the stall marker; if the top word was said, nothing is offered. If the user moves on without picking a word, an open offer is withdrawn (`self-recovered`). | Tested: session "does not offer when the user finds the word while the guess is running", "does not offer a word the user said just after the stall marker", "withdraws the offer when the user moves on without picking a word"; gate "no offer when the top word was said since the stuck point" |
| Normal thinking pause in fluent speech                       | False trigger                       | A pause alone never triggers it. It needs an unfinished phrase (ends in "the", "to", "and"…), a cue phrase, or a stall marker before a description.                                                         | Tested: detect "fluent speech is never stuck"; eval: not_stuck items. Known false triggers are listed in the StuckDetector notes in ARCHITECTURE.md                                                                                                                                                |
| Low confidence                                               | Wrong word shown                    | The gate stays silent unless the top candidate is at least `GATE_MIN_CONFIDENCE` (0.6). Extra candidates need half of that.                                                                                 | Tested: gate "offers at exactly minConfidence, not just below it"                                                                                                                                                                                                                                  |
| Several plausible words ("doctor" vs "nurse")                | Wrong pick                          | Up to 3 candidates, best first, only if the top one is confident.                                                                                                                                           | Tested: gate "limits to 3 candidates and sorts by confidence"                                                                                                                                                                                                                                      |
| Personal names, places, pets                                 | Generic guesses miss                | An optional profile file (`PROFILE_PATH`) and the meeting brief are added to the prompt. How much this helps is not measured.                                                                               | Tested: guesser "includes brief, profile words and the recent text"; profile.test. Effect on accuracy: not measured                                                                                                                                                                                |
| Semantic paraphasia ("table" said for "chair")               | User says a wrong word, not a pause | Nothing: it only reacts to stalls, not to wrong words.                                                                                                                                                      | Limitation                                                                                                                                                                                                                                                                                         |
| Speech-to-text mishears                                      | Bad context, bad guess              | Nothing special. The STT word confidence is passed through but not used, so a mishearing goes into the prompt as it is.                                                                                     | Not handled                                                                                                                                                                                                                                                                                        |
| Slow or slurred speech                                       | Pauses everywhere                   | One global pause threshold (`STUCK_PAUSE_MS`, 1500 ms by default). There is no per-user setting in the app.                                                                                                 | Not handled (global env setting only)                                                                                                                                                                                                                                                              |
| Latency over ~2.5 s                                          | Help arrives too late               | The guesser abstains after `GUESS_TIMEOUT_MS` (2500 ms). Haiku is the default model. Live latency with real Claude is not measured yet.                                                                     | Tested: guesser "abstains on a timeout, even if the client ignores the abort signal"                                                                                                                                                                                                               |
| Background noise or another speaker                          | Guessing for the wrong person       | The mic hears everyone and the prototype cannot tell speakers apart, so another person's pause or words can trigger or satisfy a guess. The Start/Stop button is the only control.                          | Limitation                                                                                                                                                                                                                                                                                         |
| Repeated triggers on the same word                           | Nagging                             | One guess per stall, a global 8 s cooldown after an offer, and a word offered in the last 8 s is not offered again. There is no per-minute cap.                                                             | Tested: session "guesses once per stall, not on every poll"; gate "blocks within the global cooldown", "does not re-offer the same word within the cooldown, whatever its spelling"                                                                                                                |
| Sensitive conversation                                       | Privacy                             | No audio is stored and transcripts stay in memory. The mic only runs after Start and stops on Stop; there is no separate pause button or listening indicator beyond that button.                            | Documented in README (Privacy); the indicator and pause are not built                                                                                                                                                                                                                              |
| No API keys                                                  | App doesn't run                     | A deterministic mock guesser and the browser's speech recognition. It covers only a few dev items.                                                                                                          | Tested: guesser "offers pharmacy for the demo line"; clean clone run with no `.env`                                                                                                                                                                                                                |
| Offline / provider error                                     | Silent failure                      | A guesser error, refusal or timeout becomes an abstain and the session carries on. The UI shows the server connection state ("reconnecting") and microphone errors, but no message for a failed guess.      | Tested: guesser "abstains when the SDK throws"; hardening "stays silent and keeps going when the guesser rejects". UI message: not handled                                                                                                                                                         |
